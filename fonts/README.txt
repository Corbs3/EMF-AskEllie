Optional: add the Fredoka font here for the full cute look.

1. Go to https://fonts.google.com/specimen/Fredoka and download the family.
2. Find the variable font file (Fredoka-VariableFont_wdth,wght.ttf).
3. Convert it to WOFF2 (for example with an online TTF to WOFF2 converter) and save it here as:
   Fredoka.woff2

Fredoka is free under the SIL Open Font License, so it's fine to bundle.
Without it, the extension uses Arial Rounded on Mac, which still looks friendly.
